# CA3: Predictive Modelling of Sligo Residential Property Sales

This repository contains the R scripts for the third assignment in my Data Science module, part of the Level 9 postgraduate programme in Big Data Analytics at Atlantic Technological University. Continuing from CA1 and CA2, the project uses Sligo residential property sales data from 2019–2025 to build, validate and appraise regression models predicting recorded full-market, second-hand transaction prices from sale timing and calendar quarter.


## Project scope
- Preparing the eligible full-market, second-hand price subset carried forward from CA1 and CA2
- Deriving continuous elapsed sale time, unordered calendar quarter and log-transformed price variables
- Splitting the dataset chronologically into 2019–2024 training records and held-out 2025 test records
- Building candidate regression models and checking model assumptions and residual diagnostics
- Validating out-of-sample predictive accuracy on held-out 2025 transactions and appraising 2025 and 2026 forecast scenarios
