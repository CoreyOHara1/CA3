# CA3: Predictive Modelling of Sligo Residential Property Sales

This repository contains the R scripts for the third assignment in my Data Science module, part of the Level 9 postgraduate programme in Big Data Analytics at Atlantic Technological University. Continuing from CA1 and CA2, the project uses Sligo residential property sales data from 2019–2025 to build, validate and appraise regression models predicting recorded full-market, second-hand transaction prices from sale timing and calendar quarter.
